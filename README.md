# OK クロード

「OK クロード」と言うと、Claudeアプリを開いて音声モードの波形ボタンを代わりにタップするAndroidアプリ。
会話そのものは公式Claudeアプリ（いつものサブスク）が行うので、API料金はかからない。

- 待ち受けは端末内の音声認識（Vosk）で処理し、音声はどこにも送らない
- ユーザー補助機能はClaudeアプリの画面だけを対象にする

## インストール

1. このリポジトリの **Releases** を開き、最新の `ok-claude.apk` をスマホでダウンロードしてインストール
   （「提供元不明のアプリ」の許可を求められたら許可）
2. アプリを開いて、画面の ①→②→③ の順に設定

## 使い方

- 「OK クロード」と言う → ブルッと震える → Claudeの音声モードが始まる
- 画面ロック中はロックを解除したタイミングで開く
- 反応しない時は、アプリの「聞こえた言葉」に何と表示されているか確認し、その言葉を「反応する言葉」に追加する

## 更新

コードを `main` に push すると GitHub Actions が自動でAPKを作り、Releases に置く。
同じ署名キーで作るので、上書きインストールで更新できる。
